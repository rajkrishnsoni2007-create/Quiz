**AI Quiz**

A lightweight, browser-based multiple-choice quiz built with HTML,
CSS, and JavaScript. The quiz presents questions about AI and
software-development fundamentals and displays the user's final score.

**Features**
- Multiple-choice questions with dynamically generated answer buttons
- Tracks correct answers and calculates a final score
- Prevents multiple answers from being counted for the same question
- Clean navy-and-gold visual theme
- Hover, active, and keyboard-focus styles for answer buttons
- No frameworks, packages, or build tools required

**Example**

A question may ask:
What does a large language model actually predict?
